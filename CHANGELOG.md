# Изменения zTrack

## 1.2.1 — 02.10.2026

- **Ассистент недели** стал точнее:
  - сводку (сколько дел, какой день загружен, сколько просрочено) теперь считает приложение, модель добавляет только короткую оценку — она больше не «теряет» задачи;
  - модель выбирает задачу и день недели из готовых списков, а не пишет даты сама, — подписи «ср 7 → пн 5» и пояснение больше не расходятся;
  - перенос предлагается, только если он реально разгружает день или ставит просроченную задачу на свободный день; на лёгкой неделе переносы не предлагаются;
  - пояснение модели, где упомянуты дни или даты, заменяется точным («Исходный день загружен сильнее: ≈2,5 ч против ≈0,5 ч»).
- **Строка добавления задачи**: при фокусе вместо подсказки показывается образец «завтра 18:30 !2 #дом»; в узких полях (боковая панель дня) клавиатурные подсказки скрываются, чтобы всё помещалось.
- Кнопка микрофона во всех строках добавления — у правого края и заметнее (акцентный фон).
- «Календарь» в боковом меню — второй после «Сегодня» (`Alt+2`).

## 1.2.0 — 02.10.2026

- **Локальный ИИ** через Ollama, модель по умолчанию — Gemma 4 E2B (`gemma4:e2b-it-qat`). Всё работает на компьютере, модель загружается только по запросу и выгружается после простоя.
  - Разбор свободной фразы в задачу: `Alt+Enter` или кнопка «✨ ИИ» в строке ввода; открывается форма с заполненными полями и плашкой «Заполнено ИИ — проверьте». Новые метки, которые предложил ИИ, добавляются одним кликом.
  - Голосовой ввод: кнопка микрофона в строке ввода (до 30 с), расшифровка той же Gemma, затем разбор в задачу.
  - «Разбить на шаги» в форме задачи.
  - Ассистент недели в недельном календаре: предложения переносов с перегруженных дней с кнопками «Перенести» / «Применить все».
  - Поиск по смыслу: блок «Похожие по смыслу» в результатах поиска (модель `embeddinggemma`, индекс в `embeddings.json`).
  - Раздел «Настройки → Локальный ИИ»: статус Ollama, скачивание моделей с прогрессом, список установленных моделей с размерами и удалением, время выгрузки модели, адрес Ollama, включение функций по отдельности.
- **Подзадачи-шаги** в форме задачи; прогресс «2/5» на карточках недели и в списках; поиск учитывает шаги.
- Приложение запрашивает доступ только к микрофону (для голосового ввода); остальные разрешения страницы запрещены.

## 1.1.0 — 30.09.2026

- Неделя в календаре переделана в доску: каждый день — колонка с крупными карточками. На карточке полностью виден заголовок, две строки заметки, время, приоритет (флажок с «!», «!!», «!!!» и цветная рамка у чекбокса) и метки (цветная полоса слева, фон карточки и подписанные метки внизу; при нескольких метках полоса делится на их цвета).
- Карточки можно перетаскивать между днями, время при этом сохраняется. В каждой колонке — быстрое добавление («+ Добавить» при наведении), двойной клик по пустому месту открывает полную форму.
- В недельном режиме боковая панель дня скрыта, чтобы колонки были шире.
- Левую панель можно свернуть до иконок: кнопка ««» внизу панели или Ctrl+B.
- Календарь запоминает выбранный вид (неделя/месяц); по умолчанию — неделя.

## 1.0.1 — 30.09.2026

- Исправлено: новая метка добавлялась дважды (Enter и потеря фокуса поля создавали её два раза). Защита добавлена и в интерфейсе, и в хранилище — метки с одинаковым названием больше не создаются.
- Уже появившиеся дубликаты меток автоматически склеиваются при запуске; задачи с дубликатом получают оригинальную метку.
- Метками теперь можно управлять прямо из боковой панели: кнопка «⋯» при наведении или правый клик — выбор цвета, «Переименовать», «Удалить» (с возможностью вернуть). Двойной клик по метке — переименование.
- Если файл данных повреждён, его копия теперь сохраняется всегда (раньше — только при наличии .bak).
- Режим разработки (`dev.bat`) использует отдельную папку данных `%APPDATA%\zTrack-dev`.
- Инструкция по обновлению в README.
