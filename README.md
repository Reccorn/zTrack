# zTrack

Личный таск-трекер с календарём для Windows. Работает полностью локально: без интернета, аккаунтов и внешних API.

## Возможности

- **Задачи и события**: создание, редактирование, удаление (с отменой), отметка выполнения
- **Разделы**: Сегодня (с просроченными), Предстоящие (7 дней), Входящие (без даты), Все задачи, Выполненные
- **Календарь**: неделя-доска (колонки дней с крупными карточками: заголовок, заметка, время, приоритет, метки) и месяц; перетаскивание задач между днями, двойной клик — создать
- **Повторы**: ежедневно / еженедельно (по дням недели) / ежемесячно / ежегодно, с интервалом и датой окончания; удалить можно одно вхождение или всю серию
- **Приоритеты и цветные метки**, фильтр по меткам в боковой панели, поиск (`Ctrl+F`)
- **Напоминания** в системных уведомлениях Windows (за 0/5/10/15/30 мин, 1–2 ч, 1 день); клик по уведомлению открывает задачу
- **Трей**: закрытие окна сворачивает в трей, напоминания продолжают приходить
- **Автозапуск с Windows** — включается/выключается в настройках (и в меню трея), опционально сразу в трей
- **Тёмная тема** в стиле Islands (светлая и «как в системе» — тоже есть)
- **Подзадачи-шаги** с прогрессом на карточках
- **Локальный ИИ** (Gemma через Ollama): разбор фраз, голосовой ввод, шаги задачи, ассистент недели, поиск по смыслу — см. раздел ниже
- **Экспорт/импорт** в JSON (объединение или замена) + автоматическая ежедневная резервная копия

### Быстрый ввод

В строке «Добавить задачу…» можно писать сразу с параметрами:

```
Позвонить маме завтра 18:30 !2 #семья
```

Понимает: `сегодня`, `завтра`, `послезавтра`, дни недели (`пт`, `в пятницу`), даты `12.10` / `12.10.2026`, время `18:30` или `в 18`, приоритет `!1`–`!3` (или `!!!`), метки `#метка` (новые создаются автоматически). `Ctrl+Enter` — открыть полную форму.

То же работает в названии новой задачи в полной форме: под полем видно, что распознано, а при переходе к другому полю (`Tab`) или сохранении всё разносится по полям. Новые метки из `#метка` создаются только при сохранении.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+N` | Новая задача |
| `Ctrl+F` | Поиск |
| `Ctrl+B` | Свернуть/развернуть левую панель |
| `Alt+Enter` | Разобрать фразу локальным ИИ |
| `Alt+1…6` | Переключение разделов |
| `Ctrl+Enter` | Сохранить в форме |
| `Esc` | Закрыть форму |
| `Пробел` / `Delete` | Отметить / удалить выбранную строку |
| `Ctrl+←/→` | Листать календарь |

## Сборка .exe

Нужен [Node.js](https://nodejs.org) (LTS, 20.19+ или 22+).

1. Запустите **`build.bat`** двойным кликом.
2. Через несколько минут откроется папка `dist`:
   - `zTrack-Setup-1.0.0.exe` — установщик (**рекомендуется**: создаёт ярлыки в «Пуске» и на рабочем столе, с ним стабильнее работают уведомления Windows);
   - `zTrack-Portable-1.0.0.exe` — версия без установки.

Вручную то же самое:

```bash
npm install
npm run build:win
```

Для разработки с горячей перезагрузкой: `dev.bat` или `npm run dev`.

## Как обновлять и вносить изменения

Данные хранятся отдельно от программы, так что переустановка и обновление их не затрагивают.

**Обычный цикл изменений:**

1. **Правите код** в `src/` (сами или просите Claude в этом проекте — он редактирует файлы прямо в этой папке).
2. **Смотрите результат вживую:** `dev.bat` (или `npm run dev`) запускает приложение с горячей перезагрузкой — правки интерфейса видны сразу, без пересборки. В dev-режиме данные хранятся отдельно (`%APPDATA%\zTrack-dev`), так что эксперименты не трогают ваши рабочие задачи.
3. **Поднимаете версию** в `package.json` (`"version": "1.0.2"`) — или командой `npm version patch --no-git-tag-version`. Версия видна в «Настройки → О программе», и по ней Windows понимает, что это обновление.
4. **Собираете:** `build.bat`.
5. **Устанавливаете поверх:** закройте zTrack (правый клик по иконке в трее → «Выход»), запустите новый `zTrack-Setup-x.y.z.exe` и укажите ту же папку. Старая версия заменится, задачи, метки и настройки останутся.

Для portable-версии достаточно заменить `.exe` новым.

**Рекомендация:** держите папку под git (`git init`, `.gitignore` уже есть) — тогда любую неудачную правку можно откатить, а история изменений будет под рукой. Изменения по версиям — в `CHANGELOG.md`.

Автообновления через интернет нет намеренно: приложение полностью офлайн.

## Пакет кода для ИИ (repomix)

**`pack.bat`** собирает код проекта в один Markdown-файл, который удобно отдать в чат с ИИ без доступа к папке: ревью, второе мнение, вопросы по архитектуре. Внутри — [repomix](https://github.com/yamadashy/repomix); он запускается через `npx` с закреплённой версией и не попадает ни в зависимости, ни в сборку приложения (при первом запуске npx один раз скачает его в свой кеш). Нужен Node.js 22+.

Результат — в папке `Claude outputs` (в git не попадает):

- `ztrack-pack.md` — весь код + README и CHANGELOG (на версии 1.2.1 ≈ 80 тыс. токенов);
- `ztrack-pack-compressed.md` — то же, но в `.ts` оставлены только импорты, сигнатуры, типы и комментарии (≈ 57 тыс. токенов). Файлы `.vue` всегда идут целиком: сжатие repomix для них работает плохо и только раздувает текст.

В окне также видно, какие файлы «тяжелее» всего по токенам. `ТЗ.md`, иконки и lock-файлы исключены; настройки — в `repomix.config.json`. Перед отправкой проверьте блок **Security Check**: repomix ищет случайно попавшие ключи и пароли.

## Локальный ИИ (Gemma через Ollama)

zTrack умеет пользоваться маленькой языковой моделью **Gemma 4**, которая работает на этом же компьютере через [Ollama](https://ollama.com). Задачи никуда не отправляются.

**Что умеет:**

- **Разбор фразы** — напишите в строке ввода как есть («в четверг после обеда созвон с Аней на час, напомни за 15 минут, по работе») и нажмите `Alt+Enter` или кнопку «✨ ИИ». Откроется форма с заполненными полями — проверьте и сохраните. В названии новой задачи в полной форме — так же: `Alt+Enter` или «✨ ИИ» заполняют поля прямо в открытой форме (точные `завтра`, `18:30`, `!2`, `#метка` важнее догадок модели).
- **Голосом** — кнопка микрофона в строке ввода и в названии новой задачи в полной форме (до 30 секунд). Gemma расшифрует речь и сразу разберёт её в задачу. `Enter` — закончить запись, `Esc` — отменить.
- **Шаги задачи** — в форме задачи раздел «Шаги» и кнопка «Разбить на шаги». На карточках виден прогресс «2/5».
- **Ассистент недели** — кнопка «Ассистент» в недельном календаре: предложит перенести задачи с перегруженных дней на свободные. Ничего не меняется без кнопки «Перенести».
- **Поиск по смыслу** — при поиске появится блок «Похожие по смыслу» («ремонт» найдёт «Заказать плитку для кухни»).

**Настройка (один раз):**

1. Установите Ollama с ollama.com и запустите её.
2. В zTrack: «Настройки → Локальный ИИ» → «Проверить» → «Скачать» у обеих моделей (`gemma4:e2b-it-qat` ≈ 4.3 ГБ и `embeddinggemma` ≈ 0.6 ГБ). Или в терминале:
   ```
   ollama pull gemma4:e2b-it-qat
   ollama pull embeddinggemma
   ```

**Ресурсы.** Модель загружается в память только когда вы пользуетесь ИИ и выгружается через 5 минут простоя (настраивается). Пока ИИ не используется, zTrack потребляет столько же, сколько без него. Первый запрос после простоя — на несколько секунд дольше.

**Список моделей.** В том же разделе настроек видны все модели Ollama с размерами — ненужные (например, старые Qwen) можно удалить кнопкой корзины.

**Если что-то не так:**

- «Ollama не отвечает» — запустите Ollama (значок в трее) и нажмите «Проверить».
- Голос не расшифровывается — обновите Ollama до последней версии; приём звука моделями Gemma 4 появился недавно, в некоторых версиях были ошибки. Говорите ближе к микрофону, в тишине.
- Ответы странные — попробуйте модель побольше: впишите `gemma4:e4b-it-qat` в поле «Языковая модель» и скачайте (≈ 6.1 ГБ).
- ИИ можно выключить целиком переключателем «Использовать локальный ИИ».

## Где хранятся данные

`%APPDATA%\zTrack\ztrack-data.json` (кнопка «Открыть папку данных» в настройках).
Рядом — `embeddings.json` (индекс для поиска по смыслу, пересоздаётся автоматически), `ztrack-data.json.bak` (предыдущая версия) и папка `backups` с ежедневными копиями за последние 14 дней.
При удалении программы данные не удаляются.

## Если что-то пошло не так

- **Не приходят уведомления** — проверьте «Параметры → Система → Уведомления»: включены ли уведомления для zTrack и не активен ли режим «Не беспокоить». В настройках zTrack есть кнопка «Тестовое уведомление». Для portable-версии уведомления иногда не показываются — используйте установщик.
- **Ошибка `Cannot create symbolic link` при сборке** — включите «Режим разработчика» (Параметры → Система → Для разработчиков) или запустите `build.bat` от имени администратора, затем повторите.
- **Долго скачивается Electron при `npm install`** — это разовая загрузка (~100 МБ) с GitHub, дождитесь окончания.
- **Windows SmartScreen предупреждает при запуске** — приложение не подписано цифровой подписью. Нажмите «Подробнее → Выполнить в любом случае».

## Стек

Electron · Vue 3 (Composition API) · TypeScript · Vite (electron-vite) · electron-builder. Без UI-библиотек и сетевых зависимостей.

```
src/
  main/       — главный процесс: хранилище, планировщик напоминаний, трей, автозапуск, IPC
  preload/    — безопасный мост window.api
  shared/     — типы и логика повторов (общие для main и интерфейса)
  renderer/   — интерфейс на Vue
```
